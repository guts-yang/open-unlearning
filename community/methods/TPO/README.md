# Not All Tokens Are Meant to Be Forgotten (AAAI 2026 Oral)

- Authors: Xiangyu Zhou, Yao Qiang, Saleh Zare Zade, Douglas Zytko, Prashant Khanduri, Dongxiao Zhu
- Paper Link: https://arxiv.org/abs/2506.03142
- Code Link: https://github.com/guts-yang/Unlearning-TPO

TPO (Targeted Preference Optimization) addresses the over-forgetting problem in LLM unlearning:
instead of suppressing all tokens of the forget-set answers uniformly, TPO first identifies
**Unwanted Words (UW)** — the tokens carrying the targeted private knowledge — versus
**General Words (GW)** — tokens carrying general language ability. The loss then combines a
**logit preference loss** on UW tokens (NPO-style forgetting, with the reference model's logits
on the true next tokens masked out) and a **preservation loss** (NLL) on GW tokens, so the model
forgets the target knowledge without degrading utility.

## Integration into this repo

The official implementation (torchrun + LoRA + standalone Trainer) is ported into this repo's
benchmark pipeline:

- **Trainer**: `src/trainer/unlearn/tpo.py` (`trainer=TPO`), registered in `src/trainer/__init__.py`,
  config at `configs/trainer/TPO.yaml`. The loss is a line-by-line port of the official
  `loss_type == 'tpo'` branch of `TOFU/dataloader.py`.
- **Data handler**: `src/data/qa.py::QAwithCommonWordsDataset` maps the official character-level
  `common_words` (GW) spans onto token positions (with the same Llama-3 offset-mapping fix as the
  official `TOFU/data_module.py`) and emits two label tensors: `labels` (UW-only, for the
  preference loss) and `gw_labels` (GW-only, for the preservation loss).
- **Data**: the official pre-annotated forget splits are vendored as JSON under `data/`
  (`forget{01,05,10}_with_common_words_{bert,gpt}.json`, generated by `prepare_data.py` from the
  official release). `run.sh` overrides the forget dataset to use them; the retain dataset stays
  on the default `locuslab/TOFU` hub split.

## Setup

- **Prerequisites** (same as the other methods): download the retain-model eval logs once so that
  `retain_logs_path` resolves (otherwise `forget_quality`/`privleak` fail silently):

  ```bash
  python setup_data.py --eval_logs   # -> saves/eval/tofu_Llama-3.2-1B-Instruct_retain{90,95,99}/TOFU_EVAL.json
  ```

- **Data**: already vendored under `data/`. To regenerate from a local clone of the official repo:

  ```bash
  git clone https://github.com/guts-yang/Unlearning-TPO.git /usr/local/Unlearning-TPO
  python community/methods/TPO/prepare_data.py --src /usr/local/Unlearning-TPO
  ```

- **Hyperparameters & Search Space** (official `TOFU/config/forget.yaml`): `lr=1e-5`,
  `num_epochs=10`, `weight_decay=0.01`, warmup 1 epoch (set via the experiment default
  `warmup_epochs=1.0`), effective batch 32 (official: batch 4 x grad-accum 4 x 2 GPUs; here:
  `per_device_train_batch_size=16` x `gradient_accumulation_steps=2` on 1 GPU). Default
  classifier for UW/GW annotation is `gpt` (switch to `bert` via the `classifier` variable in
  `run.sh`). `alpha=0` is plain TPO (official main results); `alpha=1` reproduces the official
  `tpo_grad_diff` variant (adds the retain-set NLL term).

  Official best `beta` values (no official values for Llama-3.2-1B; `run.sh` uses the
  Llama-3.2-3B values as defaults and provides a search grid):

  | Model | forget01 | forget05 | forget10 |
  |---------------|----------|----------|----------|
  | Llama-2-7B | 0.32 | 0.32 | 0.23 |
  | Llama-3.2-3B | 0.30 | 0.27 | 0.19 |
  | Llama-3.2-1B | search (e.g. 0.19-0.32) | search | search |

- **Computational Setup**: experiments run on a single A100-80G (Llama-3.2-1B-Instruct).

## Results

Run `run.sh` (Llama-3.2-1B-Instruct on TOFU, forget01/05/10 x retain99/95/90, unlearn + eval with
this repo's standard TOFU metrics):

```bash
bash community/methods/TPO/run.sh
```
