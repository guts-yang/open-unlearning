```bash
bash scripts/tofu_unlearn.sh
bash scripts/muse_unlearn.sh
```

## 实验设置

下文所有数字使用：

| 项目 | 细节 |
|------|------|
| 硬件 | 2 × L40s（各 48GB） |
| 分布式 | DeepSpeed ZeRO Stage 3（Accelerate） |
| 超参 | lr = 1e-5；适用时 α = 1, γ = 1, β = 0.1；有效 batch 32（每卡 8，梯度累积 4）；10 epoch；优化器 `paged_adamw_32bit` |

注意：

1. 表中只列出部分关键指标。更全的结果见 HuggingFace 数据集 [open-unlearning/eval](https://huggingface.co/datasets/open-unlearning/eval) 里的 `*_SUMMARY.json`。
2. **同样有效超参，换分布式方式或单卡，数字也可能变。** SimNPO、RMU 等对调参很敏感。下表仅作复现对照。
3. **NPO 实现**：MUSE 原仓库与 NPO 论文不完全一致。本仓库在各数据集上使用**论文原始 NPO 公式**。
